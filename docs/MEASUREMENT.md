# 측정 정의 · 2단계

집계 단위는 응답 1건입니다. 측정 묶음(배치)은 선택 질문·질문 원문 스냅샷·모델·지역·반복 횟수·실행 키와 개별 응답 ID를 보관합니다. 배치 성공은 모든 호출 완료를 의미하며, 업체 검토 완료나 지표 유효성을 보장하지 않습니다.

API_OBSERVATION의 유효 응답은 실행 SUCCEEDED + 완료된 웹 검색 호출 존재 + 업체 분석 READY입니다. 오류·출력 중단·검색 미실행·PENDING 식별은 모두 제외합니다. 일반 안내 응답도 검색 성공·식별 확정이면 언급 0건으로 포함합니다. 유형은 서로 혼합하지 않습니다. 기존 DEMO/MANUAL_UI의 기본 언급 지표는 기존 방식으로 유지하며 문맥 미분석 응답은 추천 후보 지표에서 제외합니다.

| 지표 | 분자 | 분모 |
| --- | --- | --- |
| 고객 언급률 | 확정 고객 언급이 있는 응답 | 유효 응답 |
| 추천 후보 포함률 | 고객이 RECOMMENDATION으로 확인된 응답 | 유효·문맥 분석 완료 응답 |
| 공식 홈페이지 인용률 | 인용 호스트가 고객 공식 호스트와 일치하는 응답 | 유효 응답 |
| 경쟁사별 언급률 | 해당 등록 경쟁사가 확정 언급된 응답 | 유효 응답 |
| 소개 위치 | 추천 후보에 명시된 숫자 | 비율 분모 없음, 원문별 기록 |
| 질문별·KST 날짜별 언급 | 해당 조건의 고객 언급 응답 | 해당 조건의 유효 응답 |

동일 업체는 한 응답에서 한 번 집계합니다. 부정·배경도 언급이지만 추천 후보는 아닙니다. 호스트는 www.만 제거하며 출처의 사실 정확성을 보장하지 않습니다. 신규 미등록 업체는 검토 후 경쟁사 등록이 가능합니다. 분모 0은 —입니다. 전체 응답·제외 수를 함께 표시합니다.

소개 순서는 명시적 번호만 저장합니다. 무번호 문단 순서·문자 오프셋을 임의 순위로 바꾸지 않습니다. 비교 화면은 질문 ID와 원문 스냅샷·모델·지역·유형이 같은 기록을 표시합니다. 질문 구성·출력 변동·검색 시점 차이 때문에 인과적 개선 성과를 보장하지 않습니다.

분석은 등록 명칭·별칭·경계, 미등록 업체 후보, 지역·유사명 충돌, 문장 부정, 추천 문맥과 목록 번호를 함께 검사합니다. 원문 근거와 오프셋·신뢰·식별 이유를 저장합니다. 오류 가능성이 있으므로 PENDING을 담당자가 연결·확정·제외하고 이유를 남깁니다. 수정 전후 이력을 보존하며 원문은 불변입니다. 담당자 수정 이후 자동 재분석으로 덮어쓰지 않습니다. 과거 모든 자동 분석 스냅샷 누적은 후속 과제입니다.

DEMO는 가상, MANUAL_UI는 소비자 화면 수동, API_OBSERVATION은 공식 API입니다. legacy API 유형은 별도로 유지합니다. API 비용 미확인은 null이며 0원으로 해석하지 않습니다. 홍제 A치과 기존 DEMO 5건의 고객 언급·공식 도메인 출처는 각각 3/5입니다. 이를 실제 검색 성과로 해석하지 않습니다.

## 3단계 수동 관측
새 수동 유형은 MANUAL_OBSERVATION이다. 과거 MANUAL_UI는 변경하지 않고 별도 유지한다. 새 수동 관측도 업체 분석 READY만 유효 표본이며 불확실한 식별은 제외한다. DEMO는 기본 대시보드와 실제 홈페이지 격차 근거에서 제외한다. 수동 예약 확인 상태·근거·시각을 별도로 저장하고 CSV에 포함한다. 전후 비교는 모델·지역을 명시해야 지표를 표시하며 질문 원문 스냅샷도 대조한다. 수동 수정 기록과 LIVE/DEMO 웹 검사도 분리한다.
