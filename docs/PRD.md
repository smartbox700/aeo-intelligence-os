# 제품 요구사항 · 로컬 v1.0 · 2단계

목표: 한국의 마케팅 담당자가 고객사의 AI 응답 내 언급과 출처를 관측하고 홈페이지 개선 작업을 근거와 함께 관리한다. 가시성 향상이나 특정 순위를 보장하지 않는다.

사용자는 로컬 단일 운영자다. 후속 SaaS에서는 조직 관리자, 대행사 담당자, 고객 열람 권한을 분리한다.

## 확정 범위

고객 CRUD, 공식 홈페이지·예약·전문가·경쟁 업체·별칭 등록, 홍제역 질문 생성 및 개별 질문 추가, ChatGPT/Gemini/네이버 AI 검색 수동 응답 입력, 원문·출처·조건 저장, 근거·신뢰·문맥 기반 업체 분석 및 담당자 수정, 기본 홈페이지 기술 진단, 근거 기반 과제, 한글 대시보드, 날짜·플랫폼·유형 필터, CSV.

## 데이터 진실성

DEMO와 실제 수동 관측은 별도 유형이다. OpenAI Responses/web_search 실측을 API_OBSERVATION으로 저장하며 DEMO/MANUAL_UI와 분리한다. 검색량, 내부 추천 알고리즘, 미확인 자격, 예약 가능 여부를 추정 사실로 표시하지 않는다. 출처와 홈페이지 구조는 개선 가설의 근거이며 추천의 직접 원인을 증명하지 않는다.

## 수용 기준

첫 화면, 고객 등록·수정·조회·삭제, 질문 생성·저장, 수동 응답 저장 후 새로고침 유지, 언급 집계, 진단·과제 표시, 과제 상태 변경, CSV 내보내기, 유형 분리, 프로젝트 외 질문 ID 차단. 실제 공개 홈페이지 진단은 입력 URL에 대해 공개 네트워크만 접근하고 실패는 오류로 표시한다.

## 범위 밖

OpenAI 외 제공사 실측, 수집 스케줄, 인증, 다중 조직 UI, 지불·구독, PDF, AI 자동 글 생성, 진단 결과로 웹사이트 자동 수정, 자동 법규 준수 판정. 소비자 측정 화면의 접근 제약을 우회하지 않는다.

## 2단계 수용 기준
실측 연구소, 요청 질문 4개, 서버 키 미설정 비활성화, 배치/개별 호출 저장, 인용·사용량·오류, 식별 검토, 유효 분모 지표와 조건 비교, 경쟁사 홈페이지 비교를 제공한다. 기본 질문 1개·반복 1회, 중복/비용/동시 실행 제한을 적용한다. 실제 API 호출 검증은 키 설정 전까지 미완료이며 모의 통합 테스트와 구별한다.


## 3단계 확정 범위
LIVE_AI_ENABLED 기본 false의 서버 비용 차단, MANUAL_OBSERVATION과 예약 확인 근거, 지역 서비스/상품 프로필, 공개 경쟁사 비교, 격차 스냅샷, 100점 내부 우선순위, 담당자·검토·진행 이력, 기간별 관측/수정 기록을 추가한다. 상세 기준은 STAGE3.md를 따른다. 공개 서비스·유료 실측·자동 사이트 수정은 범위 밖이다.


## 4단계 수용 기준
CONSUMER_UI_MANUAL 소비자 화면 수집 조건, 공식 서비스 열기·질문 복사, 일괄 CSV/JSON, 선택 이미지 증빙(OCR 미실행), 플랫폼별 표본·분모, 동일 조건 Baseline/Follow-up 및 반복 슬롯, 관측 근거 개선 과제, 기본 유료/무료 API 차단을 추가한다. Gemini 어댑터는 모의 테스트로 검증하고 계정 무료 등급 증명 수단이 없으면 호출을 차단한다. 상세 범위와 한계는 docs/STAGE4.md에 정의한다.

## 5단계 확정 범위

직접 수주형 내부 운영을 위한 업종별 고객 온보딩, 표준 프로젝트 단계와 근거 검사, 기존 진단 과제에서 수정안·고객 승인·실행 작업 연결, 동일 조건 전후 비교, 생성 시점 HTML 보고서 원본과 승인 버전, 기본 영업·계약·청구·원가, 직원 역할 및 고객 프로젝트 범위, 접근/변경 기록을 추가한다. 보고서 PDF는 브라우저 인쇄로 제공한다. 기존 범위 밖 항목 중 내부 직원 인증과 HTML/PDF 보고서는 이번 단계에 포함한다. 유료 API·자동 사이트 수정·자동 법규 판단·공개 SaaS는 범위 밖이다. 상세 구현/제약과 검증은 STAGE5.md 및 STAGE5-VALIDATION.md를 따른다.
