## 구현 범위

- 기존 Pre-Scan / 고정 질문 / 영업 Snapshot·보고서를 협약에 연결한다. 실제 고객 유형은 검수 승인된 실제 유형의 유효 표본이 필요하다.
- 협약 초안, 범위 새 버전, 내부 검토 → 고객 검토 → 합의 → 실제 시작 → 완료/중도 종료를 관리한다. 확인 증빙·현재 버전·실제 날짜·필수 권한 없이 시작할 수 없다.

- 실제 시작일을 기준으로 Day 0~30 일정을 계산한다. 일정 이동·연기·제외는 사유와 이력을 남기며 기한 경과만으로 완료되지 않는다.
- 기존 실행 과제와 Pilot 업무를 연결한다. 계획/실제 시간, 내부 단가, 외부비용, 현재 작업 버전, 규정 검토·심의, 승인·적용·완료 증빙을 관리한다. 제공 범위 초과는 범위 변경 또는 OWNER 예외 확인이 필요하다.

`/api/pilot/documents`는 5MB 이하 PDF/PNG/JPEG/WebP 증빙 등록·다운로드를 제공한다. 실제 파일은 `data/pilot-documents/`에 UUID로 저장하며 경로·해시·소속을 재검사한다. 서버는 사용자 확인을 기록하며 환자 정보가 없음을 자동 인증하지 않는다. 증빙 파일 자체와 `data/sales-brand.json`은 DB 논리 백업에 포함되지 않으므로 별도로 보존해야 한다.

OWNER/MANAGER만 Pilot 관리에 접근한다. 제안 가격·계약·범위 예외·원가 단가는 OWNER 전용이다. MANAGER 응답에서 내부 원가/계약 금액과 계약 문서를 제외하고 ANALYST의 일반 workspace 응답에는 Pilot 운영 자료를 포함하지 않는다. 계약 문서 직접 다운로드도 OWNER 권한을 재검사한다. 일반 영업 화면에서도 체결 확인 없는 WON을 차단하고 Pilot 계약 조건 변경은 계약 전환으로 제한한다.
