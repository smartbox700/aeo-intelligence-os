초기 신규 단위 시험에서 상품 Organization에 실제 상품 초안에 표시되지 않은 전화/주소/시간이 포함되는 문제와 HTML `<br>` 구분자에 따른 본문 대조 불일치가 발견됐다. 표시되는 사실만 구조화하고 블록/줄바꿈을 공백으로 정규화하도록 수정한 재검증이 통과했다. 실패를 성공으로 표시하지 않았다.

홍제 A치과 DEMO 시험은 별도 프로젝트에서 가상 공식 사실 7개, 기존 소비자 관측 저장 방식으로 일반 안내 Baseline/Follow-up 2개를 기록한다. 특정 치과의 실제 추천 성공을 주장하는 원문을 만들지 않았다. 완료된 작업 v3의 제목·메타·H1·본문·공식 경로·JSON-LD 대조 6개가 통과했으며 그 결과는 **DEMO HTML** 대조다. 실제 고객 공개 페이지 반영 결과가 아니다.

C브랜드 고체방향제 시험은 공식 홈페이지/네이버쇼핑/쿠팡별로 문안과 지시서를 검사한다. 미확인 프랑스 향료·발향 기간·특허·인증 표현을 제외한다. 공식 사이트만 Product/Offer를 생성하고 마켓플레이스에는 JSON-LD를 생성하지 않는다.

신규 보안 시험은 익명 API 401, 다른 고객 접근 403, ANALYST의 사실 검증 변경 403, 다른 Origin 403, 내부 IP URL 400, CSP 미리보기 및 납품 비밀정보 제외를 확인한다. 기존 보안 시험도 원문 불변·SSRF·외부 Origin·프로젝트 분리를 재검증한다. 실제 네트워크 수집의 DNS/IP 고정·리디렉션별 검사·robots 정책은 기존 안전 전송을 재사용한다. 신규 LIVE 호출은 실제 고객 자료가 없어 미검증이다.

개발 전 현재 PC의 관계형 JSON 백업: `data/backups/stage5-db-before-1791521367652.json`. 기존 프로젝트 1개 / 질문 9개 / 응답 5개 / 진단 1개 / 과제 3개. 기존 writer의 불필요한 관계 ID 재생성을 수정하고, 내용이 같은 기존 관계 12개의 ID를 백업 대조 후 원래대로 보존했다. 후속 DB 통합 시험에 변경 없는 Mention/CitationSource ID 보존 검사를 추가했다.

`data/backups/stage6-preservation.json`: 업무 ID·내용·원문·payload·관계 레코드의 개발 전후 대조 결과. 기존 다른 PC DB 복원이나 DB 초기화를 수행하지 않았다. 기존 `.env`를 덮어쓰지 않았다. API 키를 브라우저/패키지/로그에 출력하지 않았다.
