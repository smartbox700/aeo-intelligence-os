## 8. 실제 직원 업무시간·원가

Pilot 작업 로그는 실제 분·선택적 시간당 원가·외부 실비를 저장하며 미입력 단가/비용은 null이다. 로그가 없거나 미확정 항목이 있으면 전체 원가를 확정하지 않는다. 전 업무를 분류한 강제 시작/종료 타이머는 없으므로 **PARTIAL**, 초기에는 수기 표와 기존 로그를 병행한다.

질문 생성/검수, 수동 AI 수집, 독립 검증, 고객 분석, 보고서 생성/검수, 개선안 작성, 고객 승인/적용, 결과보고/영업미팅을 각각 기록하는 양식을 제공했다. 실제 직원 시간·단가·실비는 **NOT_RUN**, 실제 고객 원가·인건비·수익성 **미확정**이다. 기존 LOCAL MOCK60분/합성 단가 시험과 프로그램 elapsedMs는 실제 직원 실측이 아니다.

## 9. 외부 호출 및 금지 작업

외부 유료/무료 AI API 호출 **0회**, 소비자 AI 자동 요청 **0회**, 외부 설치/다운로드 **0회**. `LIVE_AI_ENABLED=false`, `FREE_GEMINI_ENABLED=false` 원본과 시험 프로세스에서 유지했다. 기존 비용 차단/무료 Gemini networkCalls0 테스트도 통과했다. Edge PDF 렌더러는 외부 요청을 차단한다.

실제 고객 이메일/전화, 계약 체결, 고객 사이트 자동 게시, 개인정보/비밀자료 외부 공유는 모두0회다. 자동 백업 스케줄러는 승인 전이므로 등록0회다. 로컬 HTTP/DB/합성 어댑터 및 npm 오프라인 캐시는 외부 AI 실측이 아니다.

## 11. 운영 전 필수 해결사항

1. Prisma 공식 엔진 다운로드 승인 또는 승인된 로컬 엔진 제공 후 **격리 상태에서** 새 Client 생성→빌드→DB/PDF/E2E를 재실행한다. 운영 서버 DLL을 실행 중 교체하지 않는다.
2. 사용 PC/개별 직원 계정·고객 배정·공개 연락처·Edge/한글 폰트/Python 경로를 확인한다. 다른 PC는 별도 실제 실행 검증을 완료한다.
3. 키 책임자·별도 안전 보관·암호화 백업 다른 매체·보존/디스크 용량·복원 주기·실패 알림을 확정한다. 공유 ACL 없는 전용 폴더를 검증하고 일정 등록은 사용자 승인 후 수행한다.
4. 고객의 자료 사용/증빙 보관·홈페이지 수정·콘텐츠/사례 공개 권한을 별도로 확인한다. 의료/법률 문구와 실제 계약은 담당자의 최종 검토를 거친다.
5. 승인된 실제 질문10개×플랫폼2개를 수집하고 독립 검증자가 대조한다. 부분 표본·미표시 모델·검색/지역 변화는 그대로 기록한다.
6. 직원 시간·단가·실비를 실측하고 고객 단위 원가를 검수한다. 실제 실행 실패가 발생하면 전달을 중단하고 보호된 원본/실패 기록을 보존한다.
