# 8-12 첫 Pilot 준비

특정 고객을 등록하지 않았고 Pilot을 시작하지 않았습니다. 아래 체크리스트는 전부 미승인 상태입니다.

- [ ] Human Knowledge Pack approval
- [ ] Production migration complete
- [ ] Controlled feature flags activation
- [ ] Assigned project access
- [ ] Customer and project exists
- [ ] Consent reviewed
- [ ] Observation plan fixed
- [ ] Evidence sources identified
- [ ] No automatic external calls
- [ ] Verified final backup
- [ ] Recovery runbook available

고객 1개, OWNER와 담당 MANAGER/ANALYST, ChatGPT·Google AI·Gemini·Naver AI로 범위를 제한합니다. Claude·Perplexity는 선택 확장입니다.

질문 집합, 플랫폼, 채널, 반복 수, 관측 조건, baseline, action, follow-up을 실제 활성화 이후 고정합니다. 수동 Observation 정책을 사용하고 서비스·로그인 제한을 우회하지 않습니다. 접근 불가 결과를 다른 검색엔진으로 대체하지 않습니다. Naver AI가 동등한 rank를 주지 않으면 통합 ranking metric에서 제외하며 Search/Place 결과로 대체하지 않습니다.

증거가 없으면 score=null입니다. Gemini/Naver의 FACT_ONLY/NOT_CONFIGURED는 정상이며 수동 관측은 별도로 가능합니다. Action/Experiment/Insight 0도 정상입니다. 확인된 문제를 사람이 검토한 뒤 표준 Action을 별도 승인합니다.
